# Drop-in files for omacom-io/omarchy-site

| File | Goes to |
|---|---|
| `head-snippet.html` | Replace the single favicon `<link>` inside `templates/layout.html.erb` and `index.html` |
| `site.webmanifest` | Repo root of omarchy-site (`/site.webmanifest`) |
| `layout.html.erb` | Optional full replacement for `templates/layout.html.erb` if you prefer not to hand-edit |

`layout.html.erb` in this folder is the current upstream template with only the icon / PWA `<head>` tags added.
